# Система учета памятных вещей

Консольное приложение для учета памятных вещей
и оформления их выдачи (например, на выставку) на определенную дату.

## Возможности

- просмотр и поиск вещей по названию;
- добавление новых вещей;
- проверка категории вещи;
- проверка доступности вещи на дату;
- оформление и отмена выдач;
- сортировка вещей по году и отбор по году;
- статистика по коллекции;
- сохранение данных в JSON-файлах.

## Структура проекта

- main.py – точка запуска, меню и вывод данных;
- items.py – работа с памятными вещами;
- loans.py – работа с выдачами;
- storage.py – сохранение и загрузка данных;
- utils.py – безопасный ввод чисел и дат;
- data/ – JSON-файлы данных;
- tests/ – автоматизированные тесты.

## Формат данных

Вещи (`data/items.json`) – список словарей:

```json
{"id": 1, "name": "Открытка от бабушки", "category": "Письма", "year": 2015}
```

Выдачи (`data/loans.json`) – список словарей:

```json
{"id": 1, "item_id": 4, "loan_date": "2026-09-15"}
```

При запуске программа читает файлы, при изменениях – сохраняет их заново.

## Требования

- Python 3.9+;
- pytest;
- flake8.

## Запуск программы
