# Система учёта памятных вещей

## Назначение

Приложение для каталогизации, хранения и систематизации информации о памятных вещах: фотографиях, сувенирах, подарках, семейных реликвиях и других предметах, имеющих личную или историческую ценность. Система помогает не потерять историю каждой вещи, связанные с ней события, людей и даты.

## Целевая аудитория

- Люди, хранящие семейные реликвии и памятные предметы
- Коллекционеры (монеты, марки, значки, открытки и т.п.)
- Семьи, ведущие архив воспоминаний
- Музеи и частные архивы

## Предметная область

Предметная область охватывает учёт материальных объектов, обладающих эмоциональной, исторической или коллекционной ценностью. Каждая вещь описывается набором атрибутов: название, категория, дата получения, источник, связанные события и люди, фотографии, заметки.

## Основные сущности

- **Вещь** — основной объект учёта (название, описание, категория)
- **Категория** — тип вещи (сувенир, фотография, реликвия и т.д.)
- **Событие** — событие, связанное с вещью (подарок, покупка, наследие)
- **Человек** — человек, связанный с вещью (даритель, владелец)
- **Медиа** — фотографии и другие вложения
- **Тег** — метка для гибкой фильтрации

## Основные функции

- Добавление, редактирование и удаление вещей
- Загрузка фотографий и прикрепление файлов
- Разбивка по категориям и тегам
- Привязка событий и людей к вещи
- Поиск и фильтрация по параметрам
- Просмотр истории вещи в хронологическом порядке
- Экспорт данных в JSON/CSV
